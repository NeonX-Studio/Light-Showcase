# Public roadmap

This roadmap is a high-level view for visitors and collaborators. It does not expose internal task breakdowns or release commitments.

## Prototype foundation

- [x] Establish the underground-city setting and three-layer social structure.
- [x] Build the core Unreal Engine C++ project architecture.
- [x] Implement data-driven NPC, quest, interaction, and world-state foundations.
- [x] Connect structured AI-assisted dialogue and quest-generation flows.
- [x] Add persistence for key world, NPC, quest, and object state.

## Current development focus

- [ ] Complete a focused playable prototype loop in the agricultural layer.
- [ ] Expand world-state feedback so players can understand consequences without exposing every calculation.
- [ ] Improve NPC memory, attitude, and information-scope behavior across repeated interactions.
- [ ] Continue building representative industrial environments and reusable linear-scene tools.
- [ ] Strengthen validation, observability, and failure handling around AI-assisted systems.

## Longer-term direction

- [ ] Expand the prototype into a larger systemic narrative RPG.
- [ ] Add dynamic world events that can develop independently of the player.
- [ ] Establish a server-authoritative boundary for shared simulation and AI arbitration.
- [ ] Support more districts, factions, resource chains, and competing interpretations of history.
- [ ] Prepare a public playable build when the project reaches a stable showcase milestone.

Dates and release scope will be announced separately when they are ready.
